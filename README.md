# 🌌 Space Memory Game

Интерактивная браузерная игра для тренировки памяти (Memory Game), созданная на **чистом JavaScript (Vanilla JS)** с использованием архитектурного паттерна **MVC (Model-View-Controller) / Observer**. Тематика игры — планеты Солнечной системы.

## ✨ Особенности проекта

- **Архитектура чистого JS:** Полное разделение игровой логики (`GameState`) и интерфейса (`View`). Компоненты абсолютно изолированы друг от друга и общаются через события.
- **Высокая производительность:** HTML-карточки кэшируются в оперативной памяти после первого рендера, что исключает постоянные тяжелые поиски элементов в DOM-дереве (`querySelector`) при кликах и переворотах.
- **Современный HTML5 & API:** Модальные окна (таблица лидеров и экран победы) реализованы с помощью семантичного HTML-тега `<dialog>`.
- **Адаптивный интерфейс:** Игра динамически собирается через JS при помощи декларативного фабричного метода для создания элементов.
- **Таблица лидеров:** Результаты лучших игр сохраняются локально в браузере игрока (`localStorage`).

## 🚀 Инструкция по локальному запуску

Так как проект использует современные JavaScript-модули (`import`/`export`), запуск файла `index.html` простым двойным кликом в браузере не сработает из-за политики безопасности CORS. Проекту необходим локальный сервер.

### Способ 1: Использование Visual Studio Code (Самый простой)

1. Установите расширение **Live Server** в VS Code.
2. Откройте папку с проектом в редакторе.
3. Убедитесь, что вы находитесь в ветке `memory-game`.
4. Нажмите на кнопку **Go Live** в правом нижнем углу окна VS Code (или нажмите `Alt + L`, затем `Alt + O`).
5. Игра автоматически откроется в вашем браузере по адресу `http://127.0.0.1:5500`.

### Способ 2: Использование Node.js (Через консоль)

Если у вас установлен Node.js, вы можете запустить проект с помощью любого статического сервера:

1. Откройте терминал в папке проекта.
2. Запустите команду для быстрой сборки сервера (без установки):
   ```bash
   npx local-server
   ```
   _или через встроенный модуль python:_
   ```bash
   python -m http.server 8000
   ```
3. Откройте браузер и перейдите по адресу, который укажет консоль (например, `http://localhost:8080`).
